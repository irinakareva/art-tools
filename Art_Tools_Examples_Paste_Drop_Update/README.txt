Art Tools educational defaults & input update

The practice cup and classical plaster head are original, newly generated images (not copies from copyrighted photographs). They are embedded within the three app HTML files, so demos do not need internet access. They are NOT claimed as historically public-domain museum photographs.

All three apps accept: Choose file (mobile); Ctrl+V paste or drag/drop (desktop).

To update existing GitHub repo: copy the three app folders into repo root and allow overwrite of only index.html and service-worker.js. Existing icons and manifest remain unchanged.
