What the values mean
Every pixel, including the background and cast shadows, belongs to a value group. Each grouped picture has exactly 2, 3, or 4 possible grays. The crop recalculates the value boundaries for that composition.

Drawing guidance: Treat these as initial maps, not perfect artistic answer keys. Automatic cutoffs group photographed brightness, not the physical cause of that brightness. Local color (dark wood or hair) and cast/form shadow can end up in the same value group. If a boundary looks wrong, change the crop or click a different light/dark balance. Keep the manually drawn thumbnail small, flat, and simple; add gradients only in the later shaded drawing. All photo processing happens on your device; this standalone file works offline.
